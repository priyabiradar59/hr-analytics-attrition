# hr-analytics-attrition
HR Attrition Analysis using Excel - analyzing employee turnover, attrition patterns and HR KPI metrics

## 📊 Project Overview
Analyzed employee attrition data to identify key factors driving 
turnover and provide actionable insights for HR decision-making.

## 🛠️ Tools Used
- Microsoft Excel (Pivot Tables, Charts, Dashboard)
- Data Cleaning & Transformation
- KPI Tracking & Visualization

## 🎯 Business Problems Solved
1. What is the overall attrition rate?
2. Which department has highest attrition?
3. Which age group leaves most frequently?
4. Does salary impact attrition?
5. How does job satisfaction affect retention?

## 📈 Key Insights
- Overall attrition rate analyzed across departments
- Identified high-risk employee segments
- Tracked KPIs including turnover rate, avg tenure, department-wise attrition
- Built interactive Excel dashboard for HR decision-making
